# Telegram bot

Minimal Node.js bot written in JavaScript using [Telegraf](https://telegraf.js.org/).

1. Install dependencies: `npm install`.
2. Set `API_KEY=your_telegram_bot_token` in `.env` (see `.env.example`).
3. Run `npm start`.

The bot responds to `/start` and `/help`, and echoes text messages. Stop it with Ctrl+C.
